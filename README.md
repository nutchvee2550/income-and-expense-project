# 💰 Expense Tracker

แอปพลิเคชันสำหรับบันทึกและติดตามรายรับ-รายจ่ายส่วนบุคคล ช่วยให้คุณจัดการทางการเงินได้อย่างมีประสิทธิภาพ พัฒนาขึ้นด้วย React และ Vite

## ✨ Features (ฟังก์ชันการทำงาน)
- ➕ บันทึกรายการรายรับและรายจ่าย
- 📊 แสดงสรุปยอดคงเหลือและยอดรวมแต่ละประเภท
- 🗑️ ลบรายการที่ไม่ต้องการออกได้
- 📱 รองรับการใช้งานบนหน้าจอที่หลากหลาย (Responsive Design)

## 🛠️ Tech Stack (เทคโนโลยีที่ใช้)
- **Frontend:** React, Vite
- **Styling:** CSS
- **Deployment:** GitHub Pages / Vercel
